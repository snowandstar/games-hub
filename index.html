我的世界网页版：4 个版本

都不用装 Java、不用装启动器。体积从 3.6MB 到 19.2MB，网络一般的话小的进得快一些。

1.2.5 和 Classic 是早期版本，能不能顺畅运行跟机型和浏览器有关，以实际打开为准。存档存在你自己的浏览器里，换电脑或清缓存会丢。

Flash 怀旧：不用装 Flash Player

Flash 2020 年就停止支持了，这里用开源的 Ruffle 模拟器在浏览器里跑 SWF。两款都在 58MB 以上，第一次打开要下完整包，慢是正常的。

建议用电脑 Chrome 或 Edge 玩，手机浏览器基本跑不动。

随手就能玩：三款不用等

都在 1MB 以内，点开就是棋盘。手机上只有 2048 能玩，另外两款要键盘。

第一次来？先看这三条

1
大的游戏第一次要等

我的世界 1.12.2 是 19.2MB，死神VS火影两款 58.9MB 和 65.9MB。第一次打开要下完整包，等 1–3 分钟很正常；下过一次之后浏览器会缓存，再玩就快。

2
存档在你自己的浏览器里

我的世界的世界、2048 和贪吃蛇的最高分，都存在你这台设备的浏览器里。换电脑、换浏览器、清缓存都会看不到。重要存档请自己截图或另存。

3
打不开怎么办

先按 Ctrl+F5 强制刷新（浏览器会缓存旧文件）。还不行就换个浏览器，或者去留言板写清用的什么浏览器、是不是手机。

AI 助手

这是一个接你自己模型账号的对话应用，不是本站提供的免费次数。需要你自己有一个 API Key。

  1. 1点应用左下角的「设置」
  2. 2选一个服务商：DeepSeek / 豆包 / 通义 / Kimi
  3. 3把你自己申请的 API Key 填进去，就能开始对话
在新窗口打开 回游戏中心

Key 只存在你自己的浏览器里，不会上传到本站，也不会存在服务器上。换设备要重填。
